## 🚀 Major Projects

- **[Autonomous Fraud Detection & Response Network](https://github.com/NihanthBhargav/Autonomous-Fraud-Detection-Response-Network)**:
Multi-agent AI system for Indian banking fraud detection. 5 specialized agents (TMA, PRA, RAA, ABA, CLA) detect and respond to suspicious transactions in real time using Isolation Forest anomaly detection — designed for autonomous decision-making without human-in-the-loop intervention.

- **[Brew & Bloom](https://github.com/NihanthBhargav/Brew-Bloom)**:
A unique coffee shop website concept blending laboratory precision with creative coffee craftsmanship. Built with modern frontend technologies featuring an immersive, design-forward interface that brings a specialty café experience to the web.

- **[E-Commerce Recommendation System](https://github.com/NihanthBhargav/E-Commerce-Recommendation-System)**:
Customer segmentation and personalization engine for e-commerce using cluster-based recommendation systems. Segments users by behavior and serves targeted, personalized recommendations — production-style ML pipeline built for scale.

- **[Purplle Store Intelligence System](https://github.com/NihanthBhargav/Store-Intelligence.git)**:
End-to-end computer vision pipeline processing CCTV footage with YOLOv8n object detection and ByteTrack multi-object tracking. Exposes real-time store analytics (footfall, zone heatmaps, dwell time) via a REST API and live Streamlit dashboard — fully containerized with Docker. Built for the Purplle Tech Challenge 2026 (HackerEarth Round 2).
